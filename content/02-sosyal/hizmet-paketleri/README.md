# Hizmet paketleri

BTMEDYA hizmet paketleri, kampanya brief'leri, teslim kapsamları ve teklif metinleri için çalışma alanı.

Fiyat, indirim, teslim süresi, sonuç garantisi, müşteri yorumu veya referans ancak doğrulanabilir bir kaynağı varsa kullanılır. Kaynağı belirtilmeyen ticari vaat oluşturulmaz.

Müşteri bilgileri ve özel teklifler bu herkese açık depoya konulmamalıdır. Bu klasörde yalnızca paylaşılabilir, hassas bilgi içermeyen şablonlar tutulur.
