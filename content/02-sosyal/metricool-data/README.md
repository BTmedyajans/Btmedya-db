# Metricool veri arşivi

Bu klasör, ihtiyaç duyulduğunda dışa aktarılmış ve hassas bilgilerden arındırılmış raporları tutmak içindir.

İzin verilen örnekler: dönem, platform, erişim, gösterim, etkileşim, video görüntüleme ve bağlantı tıklaması gibi toplulaştırılmış performans metrikleri.

**Buraya token, parola, çerez, OAuth kodu, özel mesaj veya kişisel takipçi verisi koymayın.** Rapor dosyaları veri kaynağı ve rapor tarihi ile adlandırılmalıdır.

BTMEDYA'nın geçerli yayın mimarisi doğrudan platform OAuth/API akışını kullanabilir; bu klasörün varlığı Metricool bağlantısının etkin olduğu anlamına gelmez.
